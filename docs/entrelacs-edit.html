Outils

Sommet : clic sur le fond pour créer.
Arête : clic sur un sommet, puis un second (identique pour une boucle).
Sélection : glisser un sommet pour le déplacer (clic droit = ancrer/désancrer) ; glisser le petit point milieu d'une arête pour courber son arc (clic droit dessus = revenir à la courbure nulle) ; clic sur l'arc pour sélectionner l'arête.
Supprimer : clic sur sommet ou arête.

Relaxation

Entrelacs

Chaque arête code un croisement en son milieu, et porte les deux points de contrôle (un par bout) qui définissent chaque brin — courbe de Bézier de degré simple, tangente initiale à 30°–60° de l'arête. Clic droit sur un croisement, en vue Entrelacs, pour inverser quel brin passe dessus (« priorité à droite » ↔ « à gauche »). Avec l'édition des tangentes active : glissez les poignées vertes pour ajuster angle et longueur. Le graphe reste éditable et relaxable pendant ce temps.

Fichier

Le fichier sauvegardé contient les sommets (position, friction) et les arêtes (extrémités, raideur, longueur à vide, ordre trigonométrique, priorité), ainsi que les réglages de tangentes des croisements.
